# ☕ نظام بطاقة طلب المقهى

نظام متكامل لإدارة طلبات المقهى مع بطاقة صعود رقمية (Boarding Pass) وتحديثات فورية.

## المميزات
- ✅ بطاقة صعود رقمية بتصميم عصري
- ✅ تحديث فوري عبر Socket.io
- ✅ QR Code لكل طلب
- ✅ إشعارات داخلية وصوت واهتزاز
- ✅ لوحة تحكم للبارستا
- ✅ يعمل على iPhone و Android
- ✅ دعم الوضع المظلم (Dark Mode)
